## New

🐧 Project Key now runs on Linux as a Fcitx5 input method, with the same keys, candidates and settings as on macOS and Windows. On X11 it draws its own candidate window and 中／英 badge, which look like the ones on the other platforms. On KDE Plasma they blur what is behind them by default (候選視窗外觀: 模糊); choose 深色 for a solid window. Under Wayland, Fcitx5's own candidate panel shows the candidates. This release has no Linux package yet, so build it from source as described in `platforms/linux/README.md`. It has been tested on Ubuntu 24.04 with KDE Plasma on X11.

## Changes

📐 The candidate row has 6px of space on all four sides on every platform. Before, it had 8px on the left and 19px on the right after the page number.

## Fixes

🪟 Windows: when the engine server restarts while you are composing, for example during an update, the text you have composed so far stays as you typed it. Before, the next key replaced it.

## 繁體中文

## 新功能

🐧 Project Key 現在可以在 Linux 上以 Fcitx5 輸入法使用，按鍵、候選字與設定都和 macOS、Windows 相同。在 X11 上，它自行繪製候選視窗和中／英標記，外觀與其他平台一致；在 KDE Plasma 上預設會模糊後方的內容（候選視窗外觀：模糊），選「深色」則是不透明的視窗。Wayland 下改由 Fcitx5 自己的候選面板顯示候選字。這個版本還沒有 Linux 安裝套件，請依 `platforms/linux/README.md` 從原始碼建置。已在 Ubuntu 24.04 的 KDE Plasma（X11）上測試。

## 變更

📐 各平台候選字列的上下左右都改為 6px 的間距。之前左邊是 8px，頁碼右側是 19px。

## 修正

🪟 Windows：組字途中引擎伺服器重新啟動時（例如更新的時候），已經組好的字會照原樣留下。之前會被下一個按鍵取代。
