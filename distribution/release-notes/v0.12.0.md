## New features

- **Project Key's candidate window for XWayland apps (Linux).** On Wayland desktops other than GNOME, apps running under XWayland, such as Electron and Chromium apps started in X11 mode, now show Project Key's own candidate window and 中/英 badge instead of Fcitx5's panel. The window is drawn at the display's scale, read from `Xft.dpi` or, when that is not set, from XSETTINGS.

## 繁體中文

## 新功能

- **XWayland App 的候選視窗（Linux）**：在 GNOME 以外的 Wayland 桌面上，經 XWayland 執行的 App（例如以 X11 模式啟動的 Electron、Chromium App）改為顯示 Project Key 的候選視窗與中／英標記，不再使用 Fcitx5 的面板。視窗依螢幕的縮放比例繪製，比例取自 `Xft.dpi`，未設定時取自 XSETTINGS。
