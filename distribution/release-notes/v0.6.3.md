## New

🔢 Candidates per row. A new 每列欄數 setting on macOS, Windows, and Linux sets the candidate grid to 6, 7, 8, or 9 columns; the default remains 6. The number keys 1–9 select from the row, and the keypad selection setting follows the same count. The iOS keyboard keeps 6 columns.

💬 Mode indicator on focus. When the cursor enters an input field, the current mode, 「ㄅ」 or 「A」, appears briefly below the cursor without switching modes.

## Changes

🛠️ Windows: The protocol between the text service and the engine server is now version 4, so the text service and the server must be updated together. The installer replaces both.

## 繁體中文

## 新功能

🔢 每列候選數。macOS、Windows 與 Linux 版本新增「每列欄數」設定，可將候選格線設為 6、7、8 或 9 欄，預設仍為 6 欄。數字鍵 1–9 可選取所在列的字，數字鍵盤選字亦依相同欄數。iOS 鍵盤維持 6 欄。

💬 游標進入輸入欄位時的模式提示。游標進入輸入欄位時，游標下方短暫顯示目前的模式「ㄅ」或「A」，不會切換模式。

## 變更

🛠️ Windows：文字服務與引擎伺服器之間的通訊協定升為第 4 版，兩者須一併更新；安裝程式會同時取代兩者。
