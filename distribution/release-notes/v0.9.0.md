## New features

- **Advanced model (optional).** An advanced language model, Gemma 4 E2B with its vocabulary reduced to the tokens Chinese text requires (approximately 1.3 GB), can be downloaded from **About** in the settings. When typing pauses for 0.3 seconds, the model re-ranks the candidate sentences and selects the most probable one. Inference runs locally on the CPU; no data leaves the device. The model can be updated or removed from the same panel. Without it, candidate selection is unchanged.
- **Sentence model.** The bundled sentence model has been retrained to approximate the ranking of the advanced model.
- **Linux installer.** The installation script ends with a summary of the remaining setup steps, and locates the latest release when the GitHub API rate limit is reached. When started without a terminal, it requests administrator authentication through the desktop's pkexec dialog instead of sudo.

## Bug fixes

- A word file rewritten within a single tick of a coarse file-system clock, as on Windows, was not reloaded. Changes are now detected by modification time and file size.

## Build

- All release builds and the Linux packages (deb, rpm and Arch) are built with llama.cpp at the release specified in `LLAMA_RELEASE`.

## 繁體中文

## 新功能

- **進階模型（選用）**：可於設定的「關於」下載進階語言模型，即刪減為中文所需詞表的 Gemma 4 E2B（約 1.3 GB）。輸入停頓 0.3 秒後，由此模型重新排序整句候選，並選取機率最高者。推論於本機 CPU 執行，資料不會傳送至裝置外。可於同一處更新或移除；未安裝時，選字行為不變。
- **整句模型**：重新訓練內建的整句模型，使其排序方式接近進階模型。
- **Linux 安裝程式**：安裝腳本結束時列出其餘設定步驟；GitHub API 達到請求上限時，仍可取得最新版本。於無終端機的環境中啟動時，改以桌面的 pkexec 對話框取代 sudo 進行系統管理員驗證。

## 錯誤修正

- 修正於檔案系統時間精度較粗的平台（如 Windows）上，同一時間刻度內改寫的詞檔不會重新載入的問題。現同時比對修改時間與檔案大小。

## 建置

- 所有發行版與 Linux 套件（deb、rpm、Arch）均以 `LLAMA_RELEASE` 指定版本的 llama.cpp 建置。
