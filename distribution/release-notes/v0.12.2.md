## New features

- **Ubuntu 22.04 support (Linux).** Project Key runs on Ubuntu 22.04 and Kubuntu 22.04 with GNOME 42 or KDE Plasma 5.24, in X11 and Wayland sessions. The install command installs it from the apt repository, as on Ubuntu 24.04. On this release the settings window is the Qt version, because the GTK version requires a newer libadwaita.
- **Project Key's candidate window on KDE Plasma Wayland (Linux).** In Plasma's Wayland session, candidates appear in Project Key's own window at the caret, with the same layout, expandable grid, mouse selection and 中/英 badge as on other desktops. Previous versions showed Fcitx5's built-in panel there. Background blur requires KWin 6.7 or later; on earlier versions the window is opaque.

## Changes

- **Updated models (all platforms).** The bundled models are now models-2026-11-27. They were trained on a Taiwan Traditional Chinese corpus of about 136.7 million characters, drawn from web text, question-and-answer text, the Legislative Yuan Gazette, Wikinews, Common Voice transcripts and Wikipedia. The sentence model also carries more weight when candidate sentences are ranked.
- **Associated phrases (all platforms).** The list no longer shows the same continuation twice, and a longer phrase no longer ranks below single characters only because it has more characters.

## Removed

- **Advanced model (all platforms).** The optional advanced model (Gemma 4 E2B, approximately 1.3 GB) has been removed from the settings and welcome windows. If it was downloaded, its folder is deleted automatically the next time the input method starts. Voice input and its speech model are unchanged.

## Bug fixes

- **Clicking a suggestion while typing (all platforms).** Clicking a suggestion in the candidate row had no effect until a word had been selected. The click now selects the suggestion.
- **Install command stopped without a message (Linux).** If another apt repository on the system failed to update, for example because its signing key was missing, the install command exited without explanation ([#4](https://github.com/KoukeNeko/Project-Key/issues/4)). It now shows a notice and continues, and it reports any step that fails.
- **needrestart prompt during installation (Linux, Ubuntu 22.04).** needrestart no longer pauses the installation to ask which services to restart. It only lists them, so the display manager keeps running and the current session stays open. The uninstall command behaves the same way.
- **Building from source on KDE Plasma 5 (Linux).** On Plasma 5, building from source through the install command failed because Qt 5 was missing. The install command now installs it. When a build fails, the install command shows the build's own error.
- **Second Fcitx5 process on KDE Plasma (Linux).** After an installation from an X11 session, logging in to Wayland started two Fcitx5 processes. The install command no longer adds a Fcitx5 autostart entry on KDE, and running it again removes the entry an earlier installation added.
- **Fcitx5 crash on exit (Linux, Ubuntu 22.04).** Fcitx5 no longer crashes when it exits or restarts.
- **Settings window (Linux).** On Qt 5.15.3 (Ubuntu 22.04), the option descriptions were invisible; they now display. On GNOME with X11, the title bar shows the window's name correctly and the dock shows the Project Key icon.

## 繁體中文

## 新功能

- **支援 Ubuntu 22.04（Linux）**：Project Key 可於 Ubuntu 22.04 與 Kubuntu 22.04 的 GNOME 42 或 KDE Plasma 5.24 使用，X11 與 Wayland 工作階段皆可。安裝指令與 Ubuntu 24.04 相同，自 apt 套件庫安裝。此版本的設定視窗為 Qt 版，因為 GTK 版需要較新的 libadwaita。
- **KDE Plasma Wayland 改用 Project Key 的候選視窗（Linux）**：於 Plasma 的 Wayland 工作階段，候選字顯示於 Project Key 自己的視窗，位於游標處；版面、展開格線、滑鼠選字與中／英標記皆與其他桌面相同。先前的版本在此顯示 Fcitx5 內建的面板。背景模糊需要 KWin 6.7 以上，較舊的版本為不透明。

## 變更

- **更新模型（所有平台）**：隨附的模型更新為 models-2026-11-27，以約 1.37 億字的臺灣繁體中文語料訓練，來源包括網頁文字、問答、立法院公報、維基新聞、Common Voice 的語音轉錄文字與維基百科。排序整句候選時，整句模型所占的比重亦提高。
- **聯想詞（所有平台）**：相同的接續字詞不再重複列出；較長的詞也不再只因字數較多而排在單字之後。

## 移除

- **進階模型（所有平台）**：設定視窗與歡迎視窗不再提供選用的進階模型（Gemma 4 E2B，約 1.3 GB）。已下載者，輸入法下次啟動時會自動刪除其資料夾。語音輸入與語音模型不受影響。

## 錯誤修正

- **打字時點選候選（所有平台）**：選過字之前，點選候選列中的候選沒有反應。現在點選即選取該候選。
- **安裝指令無訊息中止（Linux）**：系統中其他 apt 套件庫更新失敗時（例如缺少簽署金鑰），安裝指令會直接結束，不說明原因（[#4](https://github.com/KoukeNeko/Project-Key/issues/4)）。現在會顯示提示並繼續安裝，任一步驟失敗時也會顯示錯誤訊息。
- **安裝時的 needrestart 詢問（Linux、Ubuntu 22.04）**：needrestart 不再中斷安裝、詢問要重新啟動哪些服務，只列出這些服務，因此顯示管理員不會重新啟動，目前的工作階段也不會中斷。移除指令亦同。
- **於 KDE Plasma 5 自原始碼建置（Linux）**：在 Plasma 5 上，經由安裝指令自原始碼建置時，會因缺少 Qt 5 而失敗；現在安裝指令會一併安裝 Qt 5。建置失敗時，安裝指令會顯示建置本身的錯誤訊息。
- **KDE Plasma 上出現兩個 Fcitx5（Linux）**：於 X11 工作階段安裝後，登入 Wayland 時會啟動兩個 Fcitx5。安裝指令在 KDE 上不再建立 Fcitx5 的自動啟動項目，重新執行時也會移除先前安裝所建立的項目。
- **Fcitx5 結束時當機（Linux、Ubuntu 22.04）**：Fcitx5 結束或重新啟動時不再當機。
- **設定視窗（Linux）**：於 Qt 5.15.3（Ubuntu 22.04）上，各選項的說明文字原本不會顯示，現已修正。於 GNOME 的 X11 工作階段，標題列正確顯示視窗名稱，Dock 也會顯示 Project Key 的圖示。
