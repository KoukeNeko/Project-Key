## Bug fixes

- **Linux installer.** When run as `curl … | sh`, the installation script could stop after installing the packages with the error "Unterminated quoted string", leaving Fcitx5 and the GNOME extension unconfigured. Package installation read from the same standard input as the script and truncated it. The script is now read in full before any of it runs.

## 繁體中文

## 錯誤修正

- **Linux 安裝程式**：以 `curl … | sh` 執行安裝腳本時，可能於安裝套件後出現「Unterminated quoted string」錯誤而中止，未完成 Fcitx5 與 GNOME 擴充功能的設定。原因為安裝套件時讀取了腳本所在的標準輸入，致使腳本遭截斷。現改為讀取完整腳本後才開始執行。
