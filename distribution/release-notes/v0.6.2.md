## New

🖱️ Mouse selection. On macOS, Windows, and Linux, clicking a candidate selects it. Clicking the page number or arrow at the end of the first row expands or collapses the candidate grid. On GNOME, this feature requires the updated extension, which loads after signing out and signing back in.

✨ Fade animations on Windows and Linux. The candidate window and Tab hint now fade in and out over 120 ms, matching macOS. Acrylic, Mica, and blur fade with the window. On GNOME, blur fading requires the updated extension. On other Wayland desktops, blur appears and disappears without fading.

## Changes

🔤 Zhuyin key replacement. With 簡拼 off, a Zhuyin key in the position where a complete syllable ends now replaces the existing symbol: ㄋㄧ followed by ㄨ produces ㄋㄨ. A key for an earlier position still starts the next syllable, so ㄖㄣㄨㄟ produces 認為. The new 省略聲調 setting on macOS, Windows, and Linux, off by default, restores the previous behavior, in which ㄕㄉㄜ produces 是的.

## Fixes

🪟 Windows: Acrylic and Mica are now ready when the candidate window, Tab hint, and 中／英 indicator appear. Previously, a window could appear before its material was drawn.

🖼️ Windows: The settings windows now display the application icon.

## 繁體中文

## 新功能

🖱️ 滑鼠選字。macOS、Windows 與 Linux 版本支援以滑鼠點選候選字；點選第一列尾端的頁碼或箭頭，可展開或收合候選格線。GNOME 須使用更新後的擴充功能，並於登出後重新登入，方可載入。

✨ Windows 與 Linux 淡入淡出動畫。候選視窗與 Tab 提示現於 120 毫秒內淡入及淡出，與 macOS 一致。Acrylic、Mica 與模糊效果均隨視窗淡入淡出。GNOME 的模糊效果淡入淡出須使用更新後的擴充功能。其他 Wayland 桌面的模糊效果不會淡入淡出，將直接出現及消失。

## 變更

🔤 注音按鍵替換規則。簡拼關閉時，於完整音節結尾位置輸入注音，將替換該位置的既有注音，例如 ㄋㄧ 後輸入 ㄨ 為 ㄋㄨ。輸入位置較前的注音，仍會開始下一個音節，例如 ㄖㄣㄨㄟ 為「認為」。macOS、Windows 與 Linux 新增「省略聲調」設定，預設關閉；開啟後恢復先前的行為，例如 ㄕㄉㄜ 為「是的」。

## 修正

🪟 Windows：候選視窗、Tab 提示與中／英標記顯示時，Acrylic 與 Mica 現已就緒。先前視窗可能於材質繪製完成前即顯示。

🖼️ Windows：設定視窗現已顯示應用程式圖示。
