## New features

- **Keyboard layouts.** ETen, Hsu, ETen 26 and IBM are available in addition to Daqian, selectable in the settings on macOS, Windows and Linux. In the Hsu and ETen 26 layouts the tone keys double as consonants; Tab therefore does not convert English typed in these layouts into Zhuyin.
- **Associated phrases (off by default).** After a commit with Enter or Tab, a row lists phrases that commonly follow the last word, for example 「法」 after 「輸入」. Shift with a digit selects a phrase; Escape or any other key dismisses the row. The phrase list is McBopomofo's.
- **Dates and times.** The readings of 今天, 昨天 and 明天 offer the date and day of the week as candidates, those of 今年, 去年 and 明年 the year, and that of 現在 the current time, in McBopomofo's formats.
- **Near sounds (off by default).** Words with ㄓ/ㄗ, ㄔ/ㄘ, ㄕ/ㄙ, ㄣ/ㄥ or ㄢ/ㄤ interchanged are listed after the words of the typed reading.
- **Out-of-order Zhuyin.** With abbreviated input off, symbols typed out of order are combined into one syllable when a tone key is pressed; for example, ㄧㄚㄐ with the first tone becomes ㄐㄧㄚ. Key sequences that already form a word as typed, such as ㄨㄗˋ, are left unchanged.
- **Appearance.** The candidate window, Tab hint and mode indicator can be light, dark or follow the system setting, which is now the default.
- **Pointer highlight.** The candidate under the pointer is highlighted.
- **Accessibility.** VoiceOver on macOS and screen readers on Windows announce the selected candidate.
- **Restore defaults.** The settings window can restore all settings to their defaults and, optionally, delete the user's phrases, excluded phrases and learned choices. Downloaded models are retained.
- **Exclusion shortcut.** Shift+Backspace excludes a candidate in the same way as Delete, for keyboards without a Delete key.
- **Windows: UI elements.** Applications that draw the input method's interface themselves, such as full-screen games and the touch keyboard, now receive the candidate list. Run `install.ps1` again after updating to enable this.
- **Windows: context.** Compositions are ranked using the text before the caret, as on macOS and Linux.
- **Linux: single-command installation.** The following command installs Project Key, configures Fcitx5 and, on GNOME, enables the shell extension:

  ```sh
  curl -fsSL https://github.com/KoukeNeko/Project-Key/releases/latest/download/install.sh | sh
  ```

  Running the command again updates the installation. On Debian 13, Ubuntu 24.04 and Fedora 43 (x86_64) it installs from the Project Key apt or dnf repository and verifies the signature of the data package; on other distributions it builds the latest release from source. `uninstall.sh` removes the installation while retaining the user's phrases and settings. The settings window offers this command as the update method.

## Bug fixes

- With Caps Lock on and the Caps Lock toggle disabled, Chinese mode produced English letters while the mode indicator still showed ㄅ半. Letters are now treated as Zhuyin keys in Chinese mode regardless of Caps Lock.
- Holding Shift during a mouse click, for example Shift+click to select text, no longer switches between Chinese and English.
- Text committed when switching away from Project Key is now learned.
- Linux: On GNOME, Fcitx5 no longer displays its own input method notification away from the caret when switching to or from Project Key; the Project Key indicator is shown at the caret instead.
- Linux: On GNOME, windows are rendered at the monitor's scale, so they remain sharp at fractional scales such as 125%, and appear at the caret in XWayland applications such as Electron applications. Log out and back in once after updating so that GNOME loads the new extension; until then, the Fcitx5 panel is used.
- Linux: The GNOME Shell extension declares support for GNOME 50 and 51 (Ubuntu 26.10).
- Linux: The GTK settings window waits for Fcitx5 to start instead of reporting that it is not running.
- Linux: Emoji data is now part of the program package, so apt and dnf installations receive updates to it.
- Windows: User profile folders with non-ASCII names, such as `C:\Users\王小明`, are supported.
- Windows: Updates started from the settings window are installed only from a folder restricted to administrators.
- Windows: Sandboxed applications can no longer read or contribute to the choices learned in other applications.
- macOS: The `.pkg` installer registers the input method for the user it was installed for.
- Engine: A damaged downloaded dictionary falls back to the bundled one; excluding the only word of a syllable no longer causes an error; leaving an application with the symbol table open no longer commits its first entry; word files are no longer left truncated when written, and are read correctly when they begin with a byte order mark; punctuation and near-sound words are no longer written to the word files.

## 繁體中文

## 新功能

- **鍵盤排列**：除大千外，新增倚天、許氏、倚天 26 鍵與 IBM，可於 macOS、Windows 與 Linux 的設定中選擇。許氏與倚天 26 鍵的聲調鍵兼作聲母，因此於這兩種排列下，Tab 不將英文轉換為注音。
- **聯想詞（預設關閉）**：以 Enter 或 Tab 送出後，候選列列出常接於最後一個詞之後的詞，例如「輸入」之後的「法」。按 Shift 加數字鍵選取；按 Esc 或其他鍵即關閉。詞表取自 McBopomofo。
- **日期與時間**：今天、昨天、明天的讀音提供日期與星期作為候選，今年、去年、明年提供年份，現在提供目前時間，格式與 McBopomofo 相同。
- **近似音（預設關閉）**：一併列出 ㄓ/ㄗ、ㄔ/ㄘ、ㄕ/ㄙ、ㄣ/ㄥ、ㄢ/ㄤ 互換後的詞，排列於所輸入讀音的詞之後。
- **注音順序容錯**：簡拼關閉時，未依順序輸入的注音於按下聲調鍵後合併為一個音節，例如 ㄧㄚㄐ 加一聲為 ㄐㄧㄚ。依輸入順序已構成詞語者（如 ㄨㄗˋ）不予合併。
- **外觀**：候選視窗、Tab 提示與模式標示可設為淺色、深色或依系統設定；預設改為依系統設定。
- **指標標示**：滑鼠指標所在的候選字以底色標示。
- **輔助使用**：macOS 的 VoiceOver 與 Windows 的螢幕閱讀器會朗讀選取中的候選字。
- **恢復預設值**：設定視窗可將所有設定恢復為預設值，並可選擇一併刪除自訂詞、排除詞與選字紀錄。已下載的模型保留。
- **排除快速鍵**：Shift+Backspace 與 Delete 同樣可排除候選字，適用於沒有 Delete 鍵的鍵盤。
- **Windows：UI 元素**：自行繪製輸入法介面的應用程式（如全螢幕遊戲與觸控鍵盤）現可取得候選清單。更新後須重新執行 `install.ps1` 以啟用此功能。
- **Windows：上下文**：組字時參考游標前的文字排序，與 macOS、Linux 相同。
- **Linux：單一指令安裝**：下列指令可安裝 Project Key、設定 Fcitx5，並於 GNOME 啟用 Shell 擴充功能：

  ```sh
  curl -fsSL https://github.com/KoukeNeko/Project-Key/releases/latest/download/install.sh | sh
  ```

  重新執行即可更新。於 Debian 13、Ubuntu 24.04 與 Fedora 43（x86_64）上，自 Project Key 的 apt 或 dnf 套件庫安裝，並驗證資料套件的簽章；於其他發行版上，自最新版本的原始碼建置。`uninstall.sh` 可移除安裝，並保留自訂詞與設定。設定視窗以此指令作為更新方式。

## 錯誤修正

- 修正於 Caps Lock 切換中英關閉且大寫鎖定開啟時，中文模式輸出英文字母、模式標示仍為 ㄅ半 的問題。中文模式下的字母現一律視為注音鍵。
- 按住 Shift 點擊滑鼠（例如 Shift+點擊選取文字）時，不再切換中英。
- 切換離開 Project Key 時送出的文字，現亦納入學習。
- Linux：於 GNOME 切換至或離開 Project Key 時，Fcitx5 不再於游標以外的位置顯示其輸入法通知，改由 Project Key 的模式標示顯示於游標處。
- Linux：於 GNOME，視窗依螢幕的縮放比例繪製，於 125% 等非整數縮放下維持清晰，並於 Electron 等 XWayland 應用程式中顯示於游標處。更新後須登出並重新登入一次，GNOME 才會載入新的擴充功能；在此之前改用 Fcitx5 的面板。
- Linux：GNOME Shell 擴充功能宣告支援 GNOME 50 與 51（Ubuntu 26.10）。
- Linux：GTK 設定視窗會等待 Fcitx5 啟動，不再回報 Fcitx5 未執行。
- Linux：表情符號資料改納入程式套件，apt 與 dnf 安裝亦可取得更新。
- Windows：支援名稱含非 ASCII 字元的使用者資料夾（如 `C:\Users\王小明`）。
- Windows：由設定視窗啟動的更新，僅自限系統管理員存取的資料夾安裝。
- Windows：沙箱應用程式不再讀取或影響於其他應用程式學得的選字。
- macOS：`.pkg` 安裝程式為其安裝對象的使用者註冊輸入法。
- 引擎：下載的詞庫損毀時改用內建詞庫；排除音節唯一的詞不再造成錯誤；於開啟符號表時離開應用程式，不再送出第一項；詞檔寫入時不再遭截斷，並可正確讀取以位元組順序標記開頭的詞檔；標點符號與近似音的詞不再寫入詞檔。
