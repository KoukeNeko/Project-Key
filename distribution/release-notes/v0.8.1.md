## New

⌨️ Keyboard layouts. ETen, Hsu, ETen 26 and IBM join Daqian, chosen in the settings on macOS, Windows and Linux. In Hsu and ETen 26 the tone keys are also consonants, so Tab does not turn English typed there into Zhuyin.

🔗 Associated phrases. With the new setting on (off by default), Enter or Tab commits the composition and a row offers the phrases that commonly follow its last word, such as 「法」 after 「輸入」. Shift with a digit picks one; Escape or any other key closes the row. The phrases are McBopomofo's.

🗓️ Dates and times. ㄐㄧㄣㄊㄧㄢ (今天), ㄗㄨㄛˊㄊㄧㄢ (昨天) and ㄇㄧㄥˊㄊㄧㄢ (明天) offer the date and weekday among their candidates, ㄐㄧㄣㄋㄧㄢˊ (今年) and its neighbours the year, and ㄒㄧㄢˋㄗㄞˋ (現在) the time, in McBopomofo's formats.

👂 Near sounds. With the new setting on (off by default), words with ㄓ/ㄗ, ㄔ/ㄘ, ㄕ/ㄙ, ㄣ/ㄥ or ㄢ/ㄤ swapped are listed after the words of the sound typed.

🔀 Zhuyin typed out of order. Without abbreviation, symbols typed out of order join into one syllable on the tone key: ㄧㄚㄐ with the first tone is ㄐㄧㄚ. Keys that already make a word as typed, such as ㄨㄗˋ, are left as they are.

🌗 Light and automatic candidate windows. The candidate window, Tab hint and 中／英 badge can be light, dark or, now the default, follow the system.

🖱️ The candidate under the pointer is highlighted.

♿ VoiceOver on macOS and screen readers on Windows read the selected candidate.

🔄 Restoring the settings. The settings window can put every setting back to its default, and optionally also remove the user's words, excluded words and learned choices. Downloaded models are kept.

⌫ Shift+Backspace excludes a candidate as Delete does, for keyboards without a Delete key.

🪟 Windows: Apps that draw the input method's UI themselves, such as full-screen games and the touch keyboard, now receive the candidates. **Run `install.ps1` again after updating** for these apps to see them.

🪟 Windows: The composition is ranked after the text before the caret, as on macOS and Linux.

🐧 Linux: One command installs Project Key, sets up Fcitx5 and, on GNOME, turns on the extension:

```sh
curl -fsSL https://github.com/KoukeNeko/Project-Key/releases/latest/download/install.sh | sh
```

Running it again updates. On Debian 13, Ubuntu 24.04 and Fedora 43 (x86_64) it installs from Project Key's apt or dnf repository and checks the data package's signature; elsewhere it builds the latest release. `uninstall.sh` removes it again and keeps the user's words and settings. The settings window offers this command as the update.

## Fixes

🔠 With Caps Lock on and its switch turned off, 中 typed English letters while the badge still showed ㄅ半. Letters are Zhuyin keys in 中 whatever the lock.

⇧ Shift held through a mouse click, such as Shift+click to select text, no longer switches 中／英.

💾 The text committed as Project Key is switched away from is now remembered.

🐧 Linux: On GNOME, Fcitx5 no longer shows its own input method popup away from the caret when switching to or from Project Key; Project Key's badge shows the switch at the caret.

🐧 Linux: On GNOME, the windows are drawn at the monitor's scale, so they are sharp at 125% and other fractional scales, and they appear at the caret in XWayland apps such as Electron apps. **Log out and in once after updating** for GNOME to load the new extension; until then Fcitx5's own panel is used.

🐧 Linux: The extension is declared for GNOME 50 and 51 (Ubuntu 26.10).

🐧 Linux: The GTK settings window waits for Fcitx5 to start instead of reporting it is not running.

🐧 Linux: New emoji now reach apt and dnf installs, as they are part of the program package.

🪟 Windows: User folders with non-ASCII names, such as `C:\Users\王小明`, work.

🪟 Windows: Updates from the settings window are installed only from an administrator-only folder.

🍎 macOS: The `.pkg` installer registers the input method for the user it installed to.

🧩 Several crashes and edge cases are fixed: a damaged downloaded dictionary falls back to the bundled one; excluding the only word of a syllable; leaving an app with the symbol table open no longer types its first entry; word files are written whole and read when they start with a byte order mark; punctuation and near-sound words are not written into the word files.

🔒 Sandboxed apps on Windows no longer read or teach the choices learned in other apps.

## 新功能

⌨️ 鍵盤排列。除大千外，新增倚天、許氏、倚天 26 鍵與 IBM，於 macOS、Windows 與 Linux 的設定中選擇。許氏與倚天 26 鍵的聲調鍵兼作聲母，因此在這兩種排列下，Tab 不會將英文轉為注音。

🔗 聯想詞。開啟新設定（預設關閉）後，以 Enter 或 Tab 送出時，候選列會列出常接在最後一個詞之後的詞，例如「輸入」之後的「法」。按 Shift 加數字鍵選取；按 Esc 或其他鍵即關閉。詞表取自 McBopomofo。

🗓️ 日期與時間。ㄐㄧㄣㄊㄧㄢ（今天）、ㄗㄨㄛˊㄊㄧㄢ（昨天）、ㄇㄧㄥˊㄊㄧㄢ（明天）的候選詞包括日期與星期，ㄐㄧㄣㄋㄧㄢˊ（今年）等包括年份，ㄒㄧㄢˋㄗㄞˋ（現在）包括目前時間，格式與 McBopomofo 相同。

👂 近似音。開啟新設定（預設關閉）後，一併列出 ㄓ/ㄗ、ㄔ/ㄘ、ㄕ/ㄙ、ㄣ/ㄥ、ㄢ/ㄤ 互換後的詞，排在所輸入注音的詞之後。

🔀 注音順序容錯。簡拼關閉時，未依順序輸入的注音於按下聲調鍵後合併為一個音節，例如 ㄧㄚㄐ 加一聲為 ㄐㄧㄚ。依輸入順序已構成詞語者不合併，例如 ㄨㄗˋ。

🌗 淺色與自動的候選視窗。候選視窗、Tab 提示與中／英標示可設為淺色、深色，或依系統切換（新的預設值）。

🖱️ 滑鼠指標所在的候選字會以底色標示。

♿ macOS 的 VoiceOver 與 Windows 的螢幕閱讀器會朗讀選取中的候選字。

🔄 恢復原廠設定。設定視窗可將所有設定改回預設值，並可選擇一併刪除自訂詞、排除詞與選字紀錄。下載的選字模型保留。

⌫ Shift+Backspace 與 Delete 同樣可排除候選字，適用於沒有 Delete 鍵的鍵盤。

🪟 Windows：自行繪製輸入法介面的應用程式，例如全螢幕遊戲與觸控鍵盤，現可取得候選字。**更新後請再執行一次 `install.ps1`**，這些應用程式才會使用。

🪟 Windows：組字時參考游標前的文字，與 macOS、Linux 相同。

🐧 Linux：一行指令即可安裝 Project Key、設定 Fcitx5，並於 GNOME 開啟擴充功能：

```sh
curl -fsSL https://github.com/KoukeNeko/Project-Key/releases/latest/download/install.sh | sh
```

再次執行即更新。於 Debian 13、Ubuntu 24.04 與 Fedora 43（x86_64）從 Project Key 的 apt 或 dnf 套件庫安裝，並驗證資料套件的簽章；其他發行版則自最新版本的原始碼建置。`uninstall.sh` 可移除，並保留自訂詞與設定。設定視窗的「更新」亦提供此指令。

## 修正

🔠 Caps Lock 切換中英關閉而大寫鎖定開啟時，中文模式會輸出英文字母，標示卻仍為 ㄅ半。現無論大寫鎖定與否，中文模式下的字母皆為注音鍵。

⇧ 按住 Shift 點擊滑鼠（例如 Shift+點擊選取文字）不再切換中英。

💾 切換離開 Project Key 時送出的文字，現亦會記住。

🐧 Linux：於 GNOME 切換至或離開 Project Key 時，Fcitx5 不再於游標以外的位置顯示自己的輸入法提示，改由 Project Key 的標示於游標旁顯示。

🐧 Linux：於 GNOME，視窗依螢幕的縮放比例繪製，於 125% 等非整數縮放下不再模糊；於 Electron 等 XWayland 應用程式中亦顯示於游標旁。**更新後請登出再登入一次**，GNOME 才會載入新的擴充功能；在此之前改用 Fcitx5 內建的面板。

🐧 Linux：擴充功能支援 GNOME 50 與 51（Ubuntu 26.10）。

🐧 Linux：GTK 設定視窗會等待 Fcitx5 啟動，不再顯示 Fcitx5 未執行。

🐧 Linux：表情符號改隨程式套件發佈，apt 與 dnf 安裝亦會取得新的表情符號。

🪟 Windows：使用者資料夾名稱含非 ASCII 字元（例如 `C:\Users\王小明`）時可正常運作。

🪟 Windows：設定視窗的更新只從僅限系統管理員的資料夾安裝。

🍎 macOS：`.pkg` 安裝程式會為安裝的使用者註冊輸入法。

🧩 修正數個當機與邊界情況：下載的詞庫損毀時改用內建詞庫；排除音節唯一的詞；開著符號表離開應用程式時不再送出第一項；詞檔完整寫入，並可讀取以 BOM 開頭的詞檔；標點符號與近似音的詞不再寫入詞檔。

🔒 Windows 的沙箱應用程式不再讀取或學習其他應用程式的選字。
