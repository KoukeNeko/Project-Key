## New features

- **Phrase file entries in the language bar menu (Windows).** The menu now includes 編輯自訂詞… and 編輯排除詞…, matching the macOS input menu. Each entry opens the corresponding file in the default text editor and creates the file if it does not exist.

## Bug fixes

- **Candidate window width (Windows, macOS).** When all candidates fit on a single page, the window width now matches the candidates instead of the full grid, consistent with Linux. The width remains constant between typing and selection.
- **Settings window sizing (Windows).** The window now opens at its final size; previously it briefly appeared at the system default size. Switching tabs no longer changes the window size.
- **Blur during fade animations (Linux, Wayland).** On compositors that support wp_alpha_modifier_v1, the background blur of a window now fades together with the window. Previously the blur remained visible as an empty box during the fade.

## 繁體中文

## 新功能

- **語言列選單新增詞檔編輯項目（Windows）**：選單新增「編輯自訂詞…」與「編輯排除詞…」，與 macOS 輸入選單一致。選取後以預設文字編輯器開啟對應檔案；檔案不存在時，會先建立檔案。

## 錯誤修正

- **候選視窗寬度（Windows、macOS）**：候選字可於單頁完整顯示時，視窗寬度依候選字調整，不再固定為完整格線寬度，與 Linux 版一致。輸入與選字期間，視窗寬度保持不變。
- **設定視窗尺寸（Windows）**：視窗開啟時即以最終尺寸顯示；先前會短暫以系統預設尺寸出現。切換分頁時，視窗尺寸亦不再變動。
- **淡入淡出時的模糊效果（Linux、Wayland）**：於支援 wp_alpha_modifier_v1 的合成器上，視窗的背景模糊會隨視窗一同淡入淡出。先前淡化過程中，模糊區域會殘留為空白方框。
