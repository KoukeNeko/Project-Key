## Bug fixes

- **GNOME Shell stability.** On GNOME, candidate window frames are now loaded directly into native memory instead of being copied through GNOME Shell's JavaScript heap. This reduces garbage-collection pressure and lowers the likelihood of a known GNOME Shell crash in its input-method handling. The underlying defect is in GNOME Shell and is not resolved by this change.

## 錯誤修正

- **GNOME Shell 穩定性**：GNOME 上，選字窗的畫面改為直接載入原生記憶體，不再經由 GNOME Shell 的 JavaScript 記憶體複製。此變更可減輕記憶體回收的負擔，降低 GNOME Shell 輸入法處理中一項已知錯誤導致當機的機率。該錯誤源自 GNOME Shell，此變更並未修正。
