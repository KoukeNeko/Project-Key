## New

🧠 Releases now include the context models and the extended dictionary. Words are ranked by the two words and characters before them, slips of an adjacent key are corrected, and the dictionary has words McBopomofo lacks, such as 簽核 and 氣象署. The models were counted from Chinese Wikipedia and the Legislative Yuan Gazette and are licensed under CC BY-SA 4.0; the dictionary is under LGPL-2.1-or-later. Both are separate files, installed with `MODELS-NOTICE.txt`, which lists their sources. The download is about 110MB, and about 330MB once installed.

🌏 Hanyu Pinyin input. Choose 輸入法: 漢語拼音 in the settings, under 按鍵 (macOS, Windows and Linux). Type 2–5 for the tones and Space for the first tone, or leave the tones out: nihao gives 你好 and keneng gives 可能. Use ' between syllables (fang'an) and v for ü. With Pinyin, `,` and `.` type 「，」 and 「。」. Adjacent-key correction and the Tab conversions between Chinese and English work only with Zhuyin.

👀 While you type a syllable without its tone, the composition shows its Zhuyin, and the candidate window shows a row of the words it could be, with the likely word highlighted. Down opens that row. The Tab hint now sits in a window of its own, beside the candidate window (macOS, Windows, Linux).

🧭 A composition carries on from the Chinese text before the cursor instead of starting a new sentence (macOS, Linux and iOS).

🐧 Linux:
- Install with Homebrew: `brew install koukeneko/tap/fcitx5-projectkey`, then `projectkey-link`.
- On GNOME, a GNOME Shell extension shows Project Key's own candidate window, Tab hint and 中／英 badge, and blurs what is behind them when the appearance is set to 模糊.
- On sway, Hyprland and other wlroots compositors under Wayland, Project Key's own windows appear at the cursor.
- Elsewhere, Fcitx5's panel takes the candidate window's colors from the Project Key theme, and Down opens the full grid there too.
- A settings window, in KDE's style on KDE and GNOME's style on GNOME: open it from the Fcitx5 menu (Project Key 設定…) or from the app menu.
- 檢查 Project Key 安裝, also in the Fcitx5 menu, shows what an install is missing.

## Changes

✨ macOS: the candidate window fades in and out. It crossfades when it switches between the typing row and the candidates. When the expanded grid no longer fits below the text, the window moves above the text and grows from there, keeping the sentence row next to the text.

🎨 The macOS menu bar and Linux show the same ㄅ icon as Windows, in its accent color.

## Fixes

🐾 Adjacent-key correction works again when you leave out tones.

🔢 When a syllable's Zhuyin candidate is too wide for the end of the first row, it starts the next row. Before, it left an empty column at the end of the first row.

🧹 macOS: 清除 in the settings clears the remembered choices again after the settings window is reopened.

🔒 Windows: the text service now talks only to the installed engine server, and the server starts only from an ordinary, non-elevated app.

## 繁體中文

## 新功能

🧠 發行版現在附有上下文模型和補詞後的詞庫。選字會參考前面的兩個詞與兩個字，按錯相鄰鍵時依上下文改讀，詞庫也補上 McBopomofo 沒有的詞，例如「簽核」「氣象署」。模型由中文維基百科與立法院公報統計而成，以 CC BY-SA 4.0 授權；詞庫以 LGPL-2.1-or-later 授權。兩者都是獨立的檔案，和列出來源的 `MODELS-NOTICE.txt` 一起安裝。下載約 110MB，安裝後約 330MB。

🌏 漢語拼音輸入。在設定「按鍵」區把「輸入法」改為「漢語拼音」（macOS、Windows、Linux）。聲調鍵為 2–5，空白鍵為一聲，也可以省略聲調：nihao 為「你好」，keneng 為「可能」。音節之間用 ' 分開（fang'an），ü 打成 v。拼音模式下 `,` 與 `.` 輸入「，」與「。」。鄰鍵修正與 Tab 中英互轉只適用於注音。

👀 音節還沒打聲調時，組字區顯示它的注音，候選視窗列出可能的字詞，並以亮色標出最可能的一個；按 ↓ 開啟這一列。Tab 提示移到候選視窗旁的獨立視窗（macOS、Windows、Linux）。

🧭 組字會接續游標前的中文，不再當成新句子的開頭（macOS、Linux、iOS）。

🐧 Linux：
- 可用 Homebrew 安裝：`brew install koukeneko/tap/fcitx5-projectkey`，再執行 `projectkey-link`。
- GNOME 上由 GNOME Shell 擴充功能顯示 Project Key 自己的候選視窗、Tab 提示與中／英標記；外觀設為「模糊」時會模糊後方的內容。
- 在 Wayland 下的 sway、Hyprland 等 wlroots 合成器上，Project Key 自己的視窗會出現在游標旁。
- 其他環境由 Fcitx5 的面板顯示候選字，配色來自 Project Key 主題，按 ↓ 同樣能展開整個候選格。
- 新增設定視窗，在 KDE 與 GNOME 上各自採用該桌面的樣式；從 Fcitx5 選單的「Project Key 設定…」或應用程式選單開啟。
- Fcitx5 選單的「檢查 Project Key 安裝」會列出安裝缺少的項目。

## 變更

✨ macOS：候選視窗出現與消失時會淡入淡出，在輸入列與選字之間切換時會交叉淡化。展開的候選格放不進文字下方時，視窗先移到文字上方再往上展開，整句預覽一直留在文字旁邊。

🎨 macOS 選單列與 Linux 改用和 Windows 相同的「ㄅ」圖示，以主題色顯示。

## 修正

🐾 省略聲調時，鄰鍵修正又能正常運作。

🔢 音節的注音候選放不進第一列最後一格時，改從下一列開始。先前第一列最後會空出一格。

🧹 macOS：重新開啟設定視窗後，又能用「清除」清掉選字紀錄。

🔒 Windows：文字服務只連線到已安裝的引擎伺服器，伺服器也只能由未提升權限的一般 App 啟動。
