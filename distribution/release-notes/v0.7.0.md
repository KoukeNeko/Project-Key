## New

🚫 Excluding words. Pressing Delete on a candidate and then Delete again hides that word, and the word is written to `exclude-phrases.txt`. Pressing Backspace directly afterwards restores it. The file can be opened from the menu and from the settings, which also open the data folder.

➕ Custom words. Pressing `+` on a candidate adds it to `phrases.txt`. While composing, Shift+Left and Shift+Right select syllables, and Enter adds the selection as a word. Backspace directly afterwards undoes the addition.

🔣 Symbols and emoji. The backtick key opens a table of symbols, and the `~` key opens a table of emoji by group. Both lists open expanded, and Escape inside an emoji group returns to the groups. A word's reading also offers its emoji after the words. The emoji come from the Traditional Chinese annotations of the Unicode CLDR.

🔠 Full-width input. Shift+Space toggles full-width characters, and the mode badge now shows the language and the width, such as 「ㄅ半」 and 「Ａ全」. The toggle can be turned off in the settings.

📦 macOS: Each release now includes a `.pkg` installer.

## Changes

🧠 What Project Key has learned now fades as more is typed, so that older choices give way to recent ones.

## Fixes

🪟 Windows: The word files are read again after every edit made by Project Key, and an emoji table saved with Windows line endings is read correctly.

## 繁體中文

## 新功能

🚫 排除詞。在候選字上連按兩次 Delete，即隱藏該詞，並將其寫入 `exclude-phrases.txt`。排除後立即按 Backspace 可還原。選單與設定均可開啟該檔案與資料夾。

➕ 自訂詞。在候選字上按 `+`，即將其加入 `phrases.txt`。組字時，以 Shift+左、右方向鍵選取音節，再按 Enter，即可將所選加入為詞。加入後立即按 Backspace 可復原。

🔣 符號與表情符號。按反引號鍵開啟符號表，按 `~` 鍵依分類開啟表情符號表。兩份清單開啟時皆已展開；在表情符號分類中按 Escape 會返回分類。輸入詞語的注音時，候選詞之後亦會列出對應的表情符號。表情符號取自 Unicode CLDR 的繁體中文註解。

🔠 全形輸入。按 Shift+空白鍵切換全形字元。模式標示現同時顯示語言與寬度，例如「ㄅ半」與「Ａ全」。此切換可在設定中關閉。

📦 macOS：每個版本現附有 `.pkg` 安裝程式。

## 變更

🧠 學習所得的內容現會隨輸入量增加而淡化，較早的選擇逐漸讓位給近期的選擇。

## 修正

🪟 Windows：Project Key 自行編輯詞檔後，會重新讀取該檔。以 Windows 換行字元儲存的表情符號表，現亦可正確讀取。
