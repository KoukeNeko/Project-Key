## New

📝 User phrases. The 自訂詞 setting provides an 編輯… button that opens `phrases.txt` in the default text editor. Each line contains one phrase followed by its Zhuyin reading, with syllables joined by `-` (for example, `小鍵 ㄒㄧㄠˇ-ㄐㄧㄢˋ`). Lines beginning with `#` are treated as comments, and the file includes these instructions when it is first created. Saved changes take effect from the next composition. User phrases take precedence over dictionary entries with the same reading and are matched with or without tones. On macOS, the input menu also includes 編輯自訂詞….

🔄 In-app updates. Beginning with this version, the 關於 section displays 更新到 followed by the version number when a newer release is available. Selecting it downloads the release, verifies it against the SHA-256 checksum published on GitHub, installs it, and opens the new version.
- Windows requests administrator permission once. Applications that are already running use the new version after they are restarted.
- Linux supports in-app updates for Homebrew installations. The update runs `brew upgrade`, which builds from source and takes several minutes, followed by `projectkey-link`, and then restarts Fcitx5. For installations built from source, 關於 continues to link to the release page.
- macOS replaces the existing ProjectKey.app with the new version, following the same procedure as the Homebrew cask, and then restarts the input method.

🧭 Settings access without the input menu. The settings can now be opened when Project Key does not appear in the system's input source list or notification area. On macOS, open Project Key again from Spotlight or Finder. On Windows, Project Key is available in the Start menu.

## Changes

🔒 The usage counts that Project Key learns from committed text, and the folder that contains them, are now readable only by the current user. On Windows, Microsoft Store apps, sandboxed apps, and low-integrity apps neither use these counts for ranking nor add to them, because the candidate order could otherwise reveal text entered in other applications.

## Fixes

🧹 Windows: 清除 in the settings again clears the remembered choices, and newly downloaded models take effect without a restart. Since version 0.4.0, the engine had disregarded both requests.

💥 Linux: The GNOME settings window no longer closes when 下載 next to 選字模型 is selected.

## 繁體中文

## 新功能

📝 自訂詞。設定中的「自訂詞」提供「編輯…」按鈕，以預設的文字編輯器開啟 `phrases.txt`。每行包含一個詞及其注音，音節之間以 `-` 連接，例如 `小鍵 ㄒㄧㄠˇ-ㄐㄧㄢˋ`。以 `#` 開頭的行視為註解；檔案首次建立時即附有上述說明。存檔後的變更自下一次組字起生效。自訂詞優先於詞庫中讀音相同的詞，並支援省略聲調輸入。macOS 的輸入法選單亦提供「編輯自訂詞…」。

🔄 應用程式內更新。自本版本起，有新版本發布時，「關於」區段會顯示「更新到」及新版本的版本號碼。選取後，系統將下載發行版本、依 GitHub 公布的 SHA-256 校驗碼進行驗證、完成安裝，並開啟新版本。
- Windows：將請求一次系統管理員權限。已在執行中的應用程式須重新啟動後，方會使用新版本。
- Linux：支援以 Homebrew 安裝的版本。更新時將執行 `brew upgrade`（由原始碼建置，需時數分鐘）及 `projectkey-link`，並重新啟動 Fcitx5。自行由原始碼建置的版本，「關於」仍連結至發行版本頁面。
- macOS：以新版本取代現有的 ProjectKey.app，程序與 Homebrew cask 相同，並重新啟動輸入法。

🧭 不經輸入法選單開啟設定。當系統的輸入法清單或通知區域未顯示 Project Key 時，仍可開啟設定。macOS 可經由 Spotlight 或 Finder 再次開啟 Project Key；Windows 可於「開始」功能表中找到 Project Key。

## 變更

🔒 Project Key 從送出文字中學習的使用次數及其所在資料夾，現僅限目前使用者讀取。在 Windows 上，Microsoft Store 應用程式、沙箱中的應用程式及低完整性應用程式，既不會依據這些次數排序，也不會增加次數，以避免候選字順序洩漏使用者在其他應用程式中輸入的內容。

## 修正

🧹 Windows：設定中的「清除」已可正常清除選字紀錄，新下載的模型亦無須重新啟動即可生效。自 0.4.0 版起，引擎未能處理這兩項要求。

💥 Linux：在 GNOME 設定視窗中選取「選字模型」旁的「下載」時，視窗不再關閉。
