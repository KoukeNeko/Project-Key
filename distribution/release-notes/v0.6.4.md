## Fixes

🛠️ Windows: Applications that were open when 0.6.3 was installed could no longer type Zhuyin, because the engine server refused their older text service. The server now accepts both. An application that started after 0.6.3 was installed must be restarted once; the installer lists the applications that need it.

💾 Learned typing is now saved at most every 5 seconds and when the cursor leaves an input field, instead of after every committed sentence. If the engine is stopped within 5 seconds of a commit, that last sentence is not remembered.

🐧 Linux: On GNOME without `XDG_RUNTIME_DIR`, the candidate window no longer writes its images under `/tmp`; Fcitx5's own candidate panel is used instead.

🧠 A damaged or truncated sentence model file is now rejected when it is loaded, instead of making the engine request a large amount of memory.

## 繁體中文

## 修正

🛠️ Windows：安裝 0.6.3 時已開啟的應用程式無法再輸入注音，因為引擎伺服器拒絕了它們較舊的文字服務。伺服器現在兩種都接受。0.6.3 安裝後才啟動的應用程式須重新啟動一次；安裝程式會列出需要重新啟動的應用程式。

💾 學到的打字記錄現最多每 5 秒存檔一次，並在游標離開輸入欄位時存檔，不再於每次送出句子後都存檔。若引擎在送出後 5 秒內被停止，最後一句不會被記住。

🐧 Linux：在沒有 `XDG_RUNTIME_DIR` 的 GNOME 上，候選視窗不再把影像寫到 `/tmp`，改用 Fcitx5 自己的候選面板。

🧠 損毀或被截斷的整句模型檔，現於載入時即被拒絕，不再讓引擎要求大量記憶體。
