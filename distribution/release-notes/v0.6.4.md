## Fixes

🛠️ Windows: Version 0.6.3 changed the protocol between the text service and the engine server, so applications that were open during its installation could no longer type Zhuyin. The engine server now accepts both the earlier and the current text service. An application that started after 0.6.3 was installed must be restarted once; the installer lists the applications that require it.

💾 Learned typing history is now written to disk at most once every 5 seconds, and when the cursor leaves an input field, rather than after every committed sentence. If the engine is stopped within 5 seconds of a commit, the most recent sentence is not retained.

🐧 Linux: On GNOME without `XDG_RUNTIME_DIR`, the candidate window no longer writes its images under `/tmp`. Fcitx5's own candidate panel is used instead.

🧠 A damaged or truncated sentence model file is now rejected when it is loaded, rather than causing the engine to request an excessive amount of memory.

## 繁體中文

## 修正

🛠️ Windows：0.6.3 版變更了文字服務與引擎伺服器之間的通訊協定，致使安裝期間已開啟的應用程式無法繼續輸入注音。引擎伺服器現同時支援先前與目前的文字服務。於 0.6.3 安裝後啟動的應用程式須重新啟動一次；安裝程式會列出須重新啟動的應用程式。

💾 學習所得的輸入記錄現最多每 5 秒寫入磁碟一次，並於游標離開輸入欄位時寫入，不再於每次送出句子後寫入。若引擎於送出後 5 秒內停止，最近一句將不會保留。

🐧 Linux：於未設定 `XDG_RUNTIME_DIR` 的 GNOME 環境中，候選視窗不再將影像寫入 `/tmp`，改用 Fcitx5 內建的候選面板。

🧠 損毀或遭截斷的整句模型檔，現於載入時即被拒絕，不再導致引擎要求過量記憶體。
