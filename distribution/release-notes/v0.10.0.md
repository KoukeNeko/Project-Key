## New features

- **Voice input (alpha).** Hold the right Alt key (the right Option key on macOS) and speak; when the key is released, what was said is typed in Traditional Chinese. Speech is recognized on the computer's CPU by Qwen3-ASR 0.6B, and the recording never leaves the computer. Voice input is off by default and is turned on under 按鍵 → 語音輸入（Alpha）. The speech model (approximately 1 GB) is not downloaded automatically; download it under 關於 → 語音模型. Hesitations such as 嗯, 呃 and 欸 at the start of a clause are left out, and words added to phrases.txt are passed to the model so that it spells them the same way. On Linux, another key can be recorded under 按鍵 → 語音輸入鍵. On macOS, the system asks for access to the microphone the first time.
- **Simplified Chinese.** With 選字 → 簡體中文 turned on, the composition, the candidates and the committed text are converted to Simplified Chinese character by character, using OpenCC's conversion table. It can also be switched from the input method menu (the language bar menu on Windows), or with Ctrl+Shift+F (⌃⇧F on macOS) once 按鍵 → 切換繁簡 is turned on; the shortcut is off by default because many applications use it to search. On Linux, the shortcut can be recorded under 按鍵 → 繁簡切換鍵.
- **Full-width in the input method menu.** The input method menu (the language bar menu on Windows) can switch between full-width and half-width, in addition to Shift+Space.

## Bug fixes

- **Fcitx5 candidate panel.** Clicking a candidate in Fcitx5's own candidate panel, used where Project Key's candidate window cannot be shown, now picks the candidate by its position, as the candidate window does.

## Known limitations

- Simplified Chinese is converted character by character, so a few words may convert incorrectly, and two Traditional candidates that convert to the same Simplified character are both listed.
- Voice input runs on the CPU; on slower computers, the text may take a few seconds to appear after the key is released.

## 繁體中文

## 新功能

- **語音輸入（Alpha）**：按住右 Alt 鍵（macOS 為右 Option 鍵）說話，放開後所說的話即以繁體中文輸入。語音由 Qwen3-ASR 0.6B 於本機的 CPU 辨識，錄音不會離開電腦。此功能預設關閉，於「按鍵 → 語音輸入（Alpha）」開啟。語音模型（約 1 GB）不會自動下載，請於「關於 → 語音模型」下載。句首或分句處的「嗯、呃、欸」不會輸入；自訂詞一併提供給模型，使其採用相同寫法。Linux 可於「按鍵 → 語音輸入鍵」錄製其他按鍵。macOS 第一次使用時，系統將詢問是否允許使用麥克風。
- **簡體中文**：開啟「選字 → 簡體中文」後，組字、候選字與送出的文字皆以 OpenCC 的對照表逐字轉為簡體中文。亦可從輸入法選單（Windows 為語言列選單）切換；開啟「按鍵 → 切換繁簡」後，按 Ctrl+Shift+F（macOS 為 ⌃⇧F）即可切換。由於許多 App 以此組合鍵搜尋，快捷鍵預設關閉。Linux 可於「按鍵 → 繁簡切換鍵」錄製其他組合鍵。
- **輸入法選單的全形切換**：除 Shift+Space 外，亦可從輸入法選單（Windows 為語言列選單）切換全形與半形。

## 錯誤修正

- **Fcitx5 候選面板**：無法顯示 Project Key 候選視窗時所用的 Fcitx5 候選面板，點選候選字時改依其位置選取，與候選視窗相同。

## 已知限制

- 簡體中文為逐字轉換，少數詞語可能轉換錯誤；轉為同一簡體字的兩個繁體候選字會同時列出。
- 語音輸入於 CPU 執行；在較慢的電腦上，放開按鍵後可能需要數秒才會輸入文字。
