## Fixes

🔤 Default characters for single syllables. In version 0.6.0, the sentence model changed the default character for 128 of 1,417 single syllables, for example 美 to 每 and 賣 to 麥. The model now applies only to compositions of two or more syllables.

🛠️ Windows: Applications that are already open can no longer restart the engine server while an installation is copying files. If a file remains locked, the installation stops within seconds and keeps the existing engine server.

## 繁體中文

## 修正

🔤 單音節的預設字。在 0.6.0 版中，整句模型改變了 1,417 個單音節中 128 個的預設字，例如「美」變為「每」、「賣」變為「麥」。整句模型現僅套用於兩個音節以上的組字。

🛠️ Windows：安裝程式複製檔案期間，已開啟的應用程式不再能重新啟動引擎伺服器。若檔案持續遭鎖定，安裝將於數秒內停止，並保留原有的引擎伺服器。
