## New features

- **Update notice in the input method menu.** The input method checks GitHub for a newer release at start and once a day. When there is one, its menu shows 更新到 *version*, which opens the settings to install it. The check can be turned off with 關於 > 自動檢查更新 in the settings.

## Bug fixes

- **Candidate window left behind (Windows).** The candidate window, the Tab hint and the mode badge are closed when an app stops using the input method, instead of staying in that app.

## 繁體中文

## 新功能

- **輸入法選單的更新提示**：輸入法於啟動時及每天一次向 GitHub 檢查新版本。有新版本時，選單會顯示「更新到 版本」，選取後開啟設定進行更新。可於設定的「關於 > 自動檢查更新」關閉。

## 錯誤修正

- **殘留的候選視窗（Windows）**：App 停止使用輸入法時，候選視窗、Tab 提示與模式提示會一併關閉，不再留在該 App 中。
