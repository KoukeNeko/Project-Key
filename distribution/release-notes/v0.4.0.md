## New

👋 A welcome window after installing walks you through adding Project Key: 加入 adds it to the system's input methods, and switching to it and typing a first word tick themselves off (macOS, Windows, Linux). macOS opens it while Project Key isn't enabled, and from 關於 in the settings; on Linux, run `projectkey-settings --welcome` after restarting Fcitx5.

📈 Project Key learns from what you send. It counts the Chinese text you commit, on this device only, and ranks the phrases you often type higher. It learns only while 記住選過的字 is on, and 清除 clears it along with the remembered choices.

🔤 簡拼 is a setting now, off by default. With it off, Project Key types like an ordinary Zhuyin input method: a lone symbol no longer stands for a whole syllable, and a key for a slot already filled replaces it (ㄅ then ㄆ gives ㄆ). Toneless syllables still chain, so ㄖㄣㄨㄟ gives 認為. iOS has no settings and types without 簡拼.

⇥ Tab sends the sentence as the preview row shows it, with the guesses in place of syllables still shown as Zhuyin. Where Tab turns your keys into English, Shift+Tab sends the prediction. Only Down opens the candidates now.

🔢 數字鍵盤選字, off by default: while you type, the keypad's 1–6 pick from the candidate row. The main row's 1–6 stay Zhuyin keys.

🎯 The candidates go on with words in the same syllables' other tones, so ㄨㄟˇ ㄗㄠˋ offers 偽造. Choosing one takes its reading; what you typed is never replaced unless you choose.

✂️ With 選字位置 set to 游標前 (the macOS default), the candidates are the words that end at the cursor, as in the system's Zhuyin: 打字 offers 字 and 自. Inside a phrase, each character can be changed on its own.

🗺️ The dictionary has Taiwan's road and district names, from 全國路名資料 (內政部戶政司, Open Government Data License v1), so intersections such as 仁和大智路口 type as one. Whole sentences come out exactly right more often: 85.0% of the CC0 test set, up from 83.9%.

⬇️ The settings show the models' date under 選字模型 and offer newer models when they're published. A download is checked against the SHA-256 that GitHub lists and takes effect without reinstalling (macOS, Windows, Linux).

## Changes

✨ The candidate window keeps its shape while you type and choose. The typing row is the row it becomes when choosing, digits and guess included, a chevron shows when there are more rows, and the width stays the same. It no longer fades out at each tone. Until you start choosing, the guess sits on a faint highlight; the accent color marks a choice.

🌊 When its content changes, the candidate window moves and resizes as one window, across the text when it changes sides, and the rows and highlight move with it; only the preview row fades between its places. It works this way on macOS, Windows and Linux, GNOME included.

🐧 Linux:
- Blur behind the candidate window on more desktops: KDE Plasma under Wayland (Fcitx5's panel, through the Project Key theme), compositors with ext-background-effect (KWin 6.7, Mutter 51, niri 26.04), and Hyprland while its `decoration:blur:input_methods` is on. sway, wayfire and COSMIC have no blur, so the window stays dark there.
- COSMIC (Pop!_OS 24.04): the candidate window sits below the text instead of over it, and the tray shows a one-color icon instead of a blank square.
- Animations run smoothly; their frames used to come 130–250ms apart.

🎨 macOS: the welcome and settings windows show Project Key's own app icon.

🖥️ Windows: the text service and the engine server must be the same version. After updating, restart the apps that were open, as the installer says.

## Removed

⚠️ Hanyu Pinyin input. If you had chosen it, Project Key is back on Daqian Zhuyin.

⚠️ Adjacent-key correction. A slip that landed on a common word could win over what you typed (ㄏㄠˇ ㄌㄢˋ came out as 好看). Keys now read as typed, as in other Zhuyin input methods.

## Fixes

🔣 Punctuation typed inside a composition starts a new phrase, so the word after it is ranked as a phrase's first word.

👁️ With 簡拼 off, a half-typed syllable shows as Zhuyin until it ends, instead of flickering between guessed words.

## 繁體中文

## 新功能

👋 安裝後會開啟歡迎視窗，引導你加入 Project Key：按「加入」即加進系統的輸入法，切換過去與試打成功後，對應的步驟會自動打勾（macOS、Windows、Linux）。macOS 在 Project Key 還沒啟用時開啟它，也可以從設定的「關於」開啟；Linux 在重新啟動 Fcitx5 後執行 `projectkey-settings --welcome`。

📈 Project Key 會從你送出的中文學習：只在這台裝置上統計，常打的說法排得更前面。只有開啟「記住選過的字」時才會學習，「清除」會連同選字紀錄一起清掉。

🔤 「簡拼」改為設定，預設關閉。關閉時和一般注音輸入法一樣：單獨一個注音不再代表整個音節，同一位置再按另一個注音會換掉它（ㄅ 後按 ㄆ 為 ㄆ）。省略聲調仍可連打，ㄖㄣㄨㄟ 為「認為」。iOS 沒有設定畫面，一律不使用簡拼。

⇥ Tab 依整句預覽送出整句，還顯示成注音的音節以猜測的字代替。Tab 用來轉成英文時，改用 Shift+Tab 送出預測。現在只有 ↓ 會開啟候選。

🔢 「數字鍵盤選字」，預設關閉：打字時數字鍵盤的 1–6 直接從候選列選字，主鍵盤的 1–6 仍是注音。

🎯 候選字之後接著列出相同音節其他聲調的詞，ㄨㄟˇ ㄗㄠˋ 會出現「偽造」。選了就採用它的讀音；沒有選的話，不會換掉你打的讀音。

✂️ 「選字位置」設為游標前時（macOS 的預設），候選改為結束在游標處的字詞，和系統注音相同：「打字」會列出「字」「自」。游標在詞中間時，每個字都能單獨更換。

🗺️ 詞庫加入全台的路名與鄉鎮市區名稱，來自全國路名資料（內政部戶政司，政府資料開放授權條款第 1 版），「仁和大智路口」這類路口也能一次打出。整句完全正確的比例在 CC0 測試集上由 83.9% 提高到 85.0%。

⬇️ 設定的「選字模型」顯示模型日期，有新模型發布時可以直接下載。下載的檔案會比對 GitHub 列出的 SHA-256，不必重新安裝就會生效（macOS、Windows、Linux）。

## 變更

✨ 打字與選字時，候選視窗維持同一個形狀：打字時的那一列就是選字時的那一列，包含數字和猜測；還有更多列時顯示箭頭；寬度也不再改變，打完聲調時也不再淡出。開始選字前，猜測的字以淡色反白標示，主題色只用來標示已選的字。

🌊 內容改變時，候選視窗整個一起移動、縮放，換到文字另一側時直接移過去，候選列與反白跟著移動，只有整句預覽列在新舊位置之間淡出淡入。macOS、Windows、Linux（包括 GNOME）都是如此。

🐧 Linux：
- 更多桌面能模糊候選視窗的背景：Wayland 下的 KDE Plasma（Fcitx5 的面板，透過 Project Key 主題）、支援 ext-background-effect 的合成器（KWin 6.7、Mutter 51、niri 26.04），以及開啟 `decoration:blur:input_methods` 的 Hyprland。sway、wayfire 與 COSMIC 沒有模糊，維持深色。
- COSMIC（Pop!_OS 24.04）：候選視窗改在文字下方，不再蓋住文字；系統匣顯示單色圖示，不再是一塊空白方塊。
- 動畫更流暢；先前每一格畫面相隔 130–250 毫秒。

🎨 macOS：歡迎與設定視窗顯示 Project Key 自己的 App 圖示。

🖥️ Windows：文字服務與引擎伺服器必須是同一版本，更新後請依安裝程式的提示重新開啟原本開著的 App。

## 移除

⚠️ 漢語拼音輸入。原本選用拼音的話，Project Key 會改回大千注音。

⚠️ 鄰鍵修正。按錯的鍵剛好組成常用詞時，可能蓋過你實際打的字（ㄏㄠˇ ㄌㄢˋ 變成「好看」）。現在照實際按的鍵讀，和其他注音輸入法相同。

## 修正

🔣 在組字中打的標點會開始新的詞組，標點後的詞改以詞組開頭的方式排序。

👁️ 關閉簡拼時，還沒打完的音節在打完前一直顯示注音，不再在猜測的字之間閃動。
