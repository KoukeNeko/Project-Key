# 補詞與上下文 bigram／trigram 訓練

產生三個檔案，輸入法建置時若存在就一併放入：

- `.cache/data.txt`：McBopomofo 詞庫補上它沒有的詞，例如「簽核」「氣象署」「飆高」。
- `.cache/bigram.bin`：詞 bigram 與 trigram 模型（約 190MB），以補詞後的詞庫斷詞訓練。組字器據此在相同讀音的詞之間，依前兩個詞選字，例如「第一」後面的 ㄌㄧㄝˋ 選「列」。
- `.cache/chars.bin`：字 trigram 模型（約 126MB），補上詞模型沒見過的詞對，例如「候選」後面的 ㄘˋ 是「字」打錯一鍵（「選字」常見，「選次」少見）。

```bash
platforms/macos/build.sh             # 先建置，取得 McBopomofo 的 data.txt
tools/bigram-trainer/train.sh        # 下載維基百科分片（約 590MB）與新酷音詞庫，補詞並訓練，約 10 分鐘
platforms/macos/build.sh             # 再建置一次，把模型放進 App
```

`train.sh [字數上限] [最少出現次數]`，預設為 2 億字、3 次。

## 做法

1. `extract.py` 從中文維基百科（20231101 版）第一個 parquet 分片取出段落。若有 `.cache/gazette/`，再加上立法院公報全文（質詢、委員會發言等口語）。公報需先另行下載：`python3 -I fetch_gazette.py .cache/gazette 11`（第 11 屆，約 3,300 份）。
2. OpenCC `s2twp` 轉成臺灣正體，再把 OpenCC 產生的佈、臺、賬改回布、台、帳。轉好的文字存成 `.cache/text-<字數上限>.txt` 重複使用；下載公報後須刪除它。
3. 補詞（`supplement.py`）：
   - 新酷音詞庫（libchewing-data，LGPL-2.1-or-later）中 McBopomofo 完全沒有的詞（約 1.4 萬）。McBopomofo 以其他讀音收錄的詞不補，保留 McBopomofo 的讀音。
   - `mine.cpp` 從訓練文字找出常相連的「詞＋單字」或「單字＋詞」，例如 氣象＋署、簽＋核：出現至少 50 次、PMI（log10）至少 2.0，且不是多半出現在更長候選詞裡的片段。單字的每個讀音各列一筆，因為 McBopomofo 的單字分數看不出哪個讀音常用（「署」的 ㄕㄨˋ、「長」的 ㄓㄤˇ 都在最低分）。兩個多字詞相連多半是片語，由上下文模型處理，不補。
   - 分數依兩邊都有的詞，按字數（2、3、4 以上）以出現次數迴歸到 McBopomofo 的分數尺度。
4. `train.cpp` 把每段連續漢字依補詞後的詞庫分數斷詞（`segment.h`，`mine.cpp` 共用），計算相鄰詞對的條件機率 P(後詞｜前詞)，保留出現次數達門檻的詞對。每段的開頭與結尾也算成詞對（空字串代表段落邊界），讓組字器知道哪些詞常出現在片語開頭或結尾，例如「什」幾乎不會結尾。
5. `chars.cpp` 計算每段連續漢字（含段落起訖）的字、字對、三字組出現次數，保留出現至少 3 次的字對與三字組（`train.sh` 的 `CHAR_MIN_COUNT`），以插值絕對折扣（D = 0.75）估計 P(字｜前兩字)，格式定義在 `core/engine/CharModel.h`。門檻提高可縮小檔案（5 次約 81MB，10 次約 46MB），但評測語料整句正確由 220 句降為 216、214 句：「把燈關」「已經寄到」這類出現不多的字組有用。

模型格式定義在 `core/engine/Bigram.h`。組字器的計分方式為 log10(0.3 × 上下文 + 0.7 × 10^詞庫分數)，上下文為 P(詞｜前詞)，有三詞資料時與 P(詞｜前兩詞) 各半混合；沒有詞對資料時退回詞庫分數。有字模型時，每個詞再加上 0.2 × log10 P(詞的各字｜前兩字)。兩個模型都以記憶體映射讀取。

## 限制

- 訓練文字只有百科：口語句尾的「吧」「啦」等詞對幾乎沒有，「了吧」會被選成「了巴」。
- 兩個模型合計約 310MB，App 大小隨之增加；以記憶體映射讀取，只有詞表（約 13.6 萬詞）與每字的索引常駐記憶體。
- 語料新詞未經人工審閱，其中有人名片段（例如「院長俊」）；補詞後評測（240 句）整句正確由 211 句增為 216 句（氣象署、疾病管制署、簽核、飆高、重構成），沒有句子因此變錯。
- 立法院公報為政府資料開放授權條款第 1 版，散布衍生物時須標示資料提供者「立法院」。
- 維基百科文字為 CC BY-SA 4.0。由它統計出的模型能否隨產品散布尚未確認，目前只供本機評測與試用。
