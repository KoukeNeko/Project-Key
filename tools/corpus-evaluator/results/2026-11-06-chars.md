# 字模型、鄰鍵修正修復與游標前文字

`projectkey` 在 2026-11-05 的 bigram（`2026-11-05-bigram.md`）之後的三項變更：

1. 鄰鍵修正修復：聲調可省略（849811c）與單獨一個注音代表音節（41775df）之後，按錯的鍵常被拆成兩個音節（ㄍㄜˋ 打成 ㄐㄜˋ 變成「飢餓」），鄰鍵修正幾乎失效。改為：這次組字已打過聲調時，接不上的注音若按錯一個相鄰鍵就說得通，留在同一個音節。
2. 字 trigram 模型（`chars.bin`，門檻 3，約 126MB），權重 0.2。
3. 組字接著游標前的漢字算，不當成句首。

語料：

- 評測語料（`tests/corpus/corpus.tsv`，240 句）。
- 個人語料：使用者自己在 Claude Code 對話中打的中文，取 4～24 字的連續漢字，依雜湊分成 dev（2,908 句，用來調參數）與 test（2,899 句，只在最後量一次）。注音由 `annotate.py` 自動標註、未複核；原文本身的錯字（「在」「再」不分）也算在標準答案裡，所以絕對數字偏低，只適合比較。語料只存在本機 `data/personal/`，不進版本庫。

## 整句正確

| | 評測語料 | 同列按錯 | 上下列按錯 | 不打聲調 | 個人 dev | 個人 test |
|---|---|---|---|---|---|---|
| 變更前（main 8eac25a） | 216 | 50 | 94 | 169 | 2387 | 2337 |
| ＋鄰鍵修正修復 | 216 | 126 | 151 | 169 | 2387 | 2337 |
| ＋字模型 0.2 | 221 | 144 | 168 | 182 | 2423 | 2378 |

聲調可省略之前（d26e376）同列按錯為 129、上下列為 161。修復版在第一個音節按錯時不修正（那時無法和單獨注音的縮寫區分），所以略低於當時。

字模型權重：評測語料與按錯在 0.25～0.3 最好（222、149、169），個人 dev 在 0.15～0.2 最好；個人 test 為 0.2 → 2378、0.25 → 2363，取 0.2。

字模型門檻：評測語料 3 → 221、5 → 216、10 → 214，與不用字模型（216）相比，只有門檻 3 有幫助，「把燈關」「已經寄到」「又誤點」這類出現 3～9 次的字組有用。把捨去字組的機率併入退回權重反而較差（220），「候選次」也因此不會改成「候選字」，所以退回權重維持 D × 相異數 ÷ 總數。

## 游標前文字

每句在隨機位置切開，前段當成已送出的文字，只打後段：

| | 個人 dev | 個人 test |
|---|---|---|
| 當成句首 | 2314/2908 | 2269/2899 |
| 接著游標前的漢字 | 2504/2908 | 2455/2899 |

只用詞模型時（沒有字模型）兩者幾乎相同（2287 與 2283）：切點常在詞中間，詞模型找不到前一個詞，字模型則用得上前兩字。

## 每鍵延遲

評測語料 240 句，這台 Mac（Apple 晶片），不含每句第一鍵：

| | P50 | P95 | 最大 |
|---|---|---|---|
| 只有詞模型 | 2.50ms | 6.68ms | 13.67ms |
| 加字模型 | 3.96ms | 19.67ms | 36.60ms |

字模型的查詢以每字的範圍索引縮小二分搜尋，並在組字器內快取 P(字｜前兩字)。尚未在 iPhone 上量。

## 回報的三個例子

| 輸入 | 變更前 | 現在 |
|---|---|---|
| 已送出「小模型」後 ㄕˋ ㄕˋ | 逝世 | 試試 |
| 單獨 ㄕˋ ㄕˋ | 逝世 | 逝世 |
| ㄏㄡˋ ㄒㄩㄢˇ ㄘˋ（ㄗ 按成 ㄘ） | 候選次 | 候選次（權重 0.3 時為候選字） |
| ㄎㄢˋ ㄕˋ ㄅㄧㄢˋ ㄕˋ ㄔㄤˊ ㄉㄨˋ ㄅㄧㄢˋ ㄔㄤˊ | 看是便是長度變長 | 看是便是長度變長 |

「逝世」「便是」是訓練文字（維基百科與立法院公報）的領域偏差：傳記常以「逝世」開頭，McBopomofo 的詞庫本身其實把「試試」「便是」排在前面。字模型與更長的上下文都改不了訓練文字沒有的用法；要改善需要聊天、技術類的訓練文字。

## 小型 transformer

`tools/lm-trainer` 的字元 GPT-2（small 14M、medium 30M）以同樣的維基百科與公報訓練，重排後整句正確沒有提升（medium 在罰分 8 時 216 → 216）。它對「候選字／候選次」「小模型試試／逝世」的判斷正確，但與字 trigram 同一份訓練文字，「試試／逝世」單獨出現時同樣選錯。字 trigram 直接在組字器裡評分，不需要神經網路執行環境，也能在 iOS 用。
