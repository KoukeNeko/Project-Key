# macOS 輸入法

InputMethodKit 注音輸入法（大千鍵盤），候選視窗採用 [A 整句校對條](../../docs/design/candidate-window/notes.md) 第 02 輪的設計。選字引擎與詞庫目前使用 McBopomofo（MIT，固定 commit），組字與按鍵邏輯在 `../../core/engine`，與 Windows 共用，不依賴 InputMethodKit；`Sources/InputController.mm` 只負責把按鍵與畫面接到 IMK。

## 建置與安裝

發行版（Apple 晶片）：

```bash
brew install --cask koukeneko/tap/project-key
```

自行建置需要 Xcode（或 Command Line Tools）與 CMake，macOS 13 以上。

```bash
platforms/macos/build.sh     # 下載並編譯引擎、產生詞庫、跑測試、輸出 build/ProjectKey.app
platforms/macos/install.sh   # 安裝到 ~/Library/Input Methods 並向系統註冊
```

安裝後會開啟歡迎視窗，按「加入」就會加進輸入方式；也可以到「系統設定 > 鍵盤 > 輸入方式」按「+」，在繁體中文下加入 Project Key。已經加入時不會再出現歡迎視窗，之後重新安裝也不需要再加一次。

移除：刪掉 `~/Library/Input Methods/ProjectKey.app`，再從輸入方式清單移除。

## 按鍵

| 狀態 | 按鍵 | 動作 |
|---|---|---|
| 組字中 | 注音鍵、聲調鍵 3 4 6 7 | 輸入注音；聲調鍵結束音節。聲調可省略：還沒拼成完整音節時，注音鍵修改它，按到已有注音的位置就換掉它（ㄅ 再按 ㄆ 為 ㄆ）；拼成完整音節後，接不上的注音開始下一個音節，不分聲調比對（ㄖㄣㄨㄟ 為「認為」）。還沒結束的音節顯示注音，結束後才變成字。打字時候選視窗只有一列，列出剛打完的詞（開啟簡拼時是還沒結束的音節）的其他候選，樣子與選字時相同，猜的詞有底色；這時主鍵盤的 1–6 仍是注音，開啟「數字鍵盤選字」時數字鍵盤的 1–6 選取這一列的字。整句預覽照設定出現。方向鍵移動游標後收起。開啟簡拼（預設關）時，單獨一個注音也代表以它開頭的音節（ㄨㄇ 為「我們」），所以按到已有注音的位置就開始下一個音節；還沒結束的音節也先猜成字，列在候選列（組字區顯示「你ㄏㄠ」） |
| | Space | 結束一聲音節；沒有還沒打聲調的注音時，開啟候選 |
| | ⇥ | 送出整句，還沒結束的音節用猜的字（你ㄏㄠ 為「你好」）；整句預覽列最右邊有 ⇥ 鍵帽。打的鍵可以轉成英文時 ⇥ 轉英文，改用 ⇧⇥ 送出 |
| | ↓ | 開啟候選。候選也列出同樣注音、不同聲調的字詞，排在打的聲調之後，所以 ㄨㄟˇ ㄗㄠˋ 也找得到「偽造」（ㄨㄟˋ ㄗㄠˋ）；整句仍照打的聲調猜。選字位置為游標前（預設，同系統注音）：游標前的詞，也列出結尾在游標、更長的詞；較短的候選是詞尾的字（「打字」之後是 ㄗˋ 的「字」「自」…，選了只換掉詞尾）；游標在詞中間時是游標前那一段（今｜天 為「今」）。選字位置為游標後：游標在句尾時從第一個可疑處開始（用方向鍵移到句尾時則是最後一個字），否則從游標後的字開始（游標在詞中間時，可單獨換掉後半的字） |
| | Enter | 送出整句；還沒打聲調的最後一個音節送出注音符號（ㄋㄧㄏㄠ 為「你ㄏㄠ」） |
| | ←、→、Home、End | 在字與字之間移動游標，新輸入的字插在游標處 |
| | Delete | 刪除一個注音符號或游標前的字 |
| | ⌦ | 刪除游標後的字 |
| | Esc | 清除未完成的注音；再按一次清除整句 |
| | ⇧ + 標點鍵 | 全形標點，例如 ⇧, 輸入「，」 |
| | 標點鍵 | `\` 或 `'` 輸入「、」，`[` `]` 輸入 `「` `」` |
| 選字中 | 1–6 | 選取所在那一列的字，選完跳到下一個可疑處（可在設定關閉，關閉時選完即結束選字） |
| | ←、→ | 移動選取 |
| | ↓ | 展開成多列候選，移到下一列的同一欄。還有其他列時，收合的候選列最右邊有 ⌄；展開後改成頁碼與 ⌃。每列 6 欄，長詞佔多欄。注音本身（如「ㄏㄡˋ」）接在第一列之後，選它會連同整句送出 |
| | Space、PageDown | 下一列；展開時往下捲 5 列 |
| | ↑ | 上一列；展開時在第一列收合，未展開時在第一列關閉候選、回到組字 |
| | PageUp | 上一列，停在第一列；展開時往上捲 5 列 |
| | Enter | 選定目前候選 |
| | Tab、⇧Tab | 跳到下一個／上一個可疑處 |
| | Esc | 展開時收合，否則回到組字 |
| | Delete | 回到組字 |
| 任何時候 | ⇪ | 在設定開啟「⇪ 切換中英」時（預設關），切換中／英，與單按 ⇧ 相同；大寫鎖定亮著時字母仍打小寫，大寫用 ⇧ |
| 任何時候 | 單按 ⇧ | 切換中／英，游標下方短暫顯示「ㄅ」或「A」 |
| 英文模式 | ⇥ | 剛才在英文模式打的大千鍵若是含聲調鍵的完整注音（如 ji3cl3），改成組字中的「我好」並切回中文；前面的英文不動。可轉換時游標下方會預覽轉換結果與 ⇥ 鍵帽；沒有預覽時 ⇥ 照常輸入。終端機（Terminal、iTerm2、Ghostty 等）收回不了已送給 shell 的字，不提供這項轉換 |
| 組字中 | ⇥ | 組字的按鍵若拼成英文單字（如 hello，且不是注音音節），改回英文並切到英文模式。可轉換時游標下方會預覽英文與 ⇥ 鍵帽，最後一個音節還沒結束時，預覽是候選視窗旁的小視窗；按過 Delete、在文字中移動游標或選過字就不再判斷 |
| 組字中 | ⌃⇧P | 開關整句預覽 |

整句預覽分兩處設定：輸入時常駐在文字旁的預覽，以及選字時候選視窗下方的預覽，各有三種模式（永遠、有可疑字時、關閉），預設都是有可疑字時，在輸入法選單的「設定…」視窗中切換，設定會保存；⌃⇧P 開關目前這一處。「設定…」也可選擇候選視窗與中英提示的外觀：Liquid Glass（macOS 26 以上的預設），或深色，選字位置（游標後或游標前），以及開關選完跳到下一個可疑處、簡拼、數字鍵盤選字（預設關）、記住選過的字（可清除紀錄；開著時也從送出的文字學習常打的說法，次數存在 `~/Library/Application Support/ProjectKey/personal.txt`，清除時一併清空）、⇪ 切換中英（預設關）、單按 ⇧ 切換中英，以及 ⇥ 的英文轉注音、注音轉英文（預設開）。最後一區「關於」列出版本、有無新版（查 GitHub 最新發行版；按「更新到」會下載發行版的 zip、核對 SHA-256，換掉 `~/Library/Input Methods/ProjectKey.app` 並重新開啟輸入法，與 Homebrew cask 的安裝方式相同）、選字模型的日期（有新模型時可以直接下載，核對 SHA-256 後不必重新安裝就生效）、授權與引擎及詞庫的來源。設定在下一次組字時生效。

選單列圖示是 `icon.tiff`：強調色底上的白色「ㄅ」，與 Windows 相同。歡迎與設定視窗的 App 圖示是 `AppIcon.icns`，由 `tools/icon/make-app-icon.swift` 依 macOS 的圖示格線從同一個「ㄅ」畫成。

## 可疑處的判斷

引擎走出的每個詞，若與同讀音的下一個候選分數差距小於 0.5（log10），就標為可疑。使用者選過的詞不再標示。這只能抓到同音詞的猶豫，抓不到斷詞錯誤，例如「重構成」被斷成「重／構成」。

## 上下文排序

有 `tools/bigram-trainer/.cache/bigram.bin` 時，`build.sh` 會把它放進 App，組字器依前兩個詞選字（bigram 與 trigram）；沒有時與 McBopomofo 的選字結果相同。同一個目錄有 `chars.bin` 時一併放入，再依前兩個字評分，補上詞模型沒見過的詞對（例如「候選」後的 ㄘˋ 改讀成「字」）。同一個目錄有 `data.txt` 時，以它取代 McBopomofo 的詞庫：補上新酷音詞庫與訓練文字中 McBopomofo 沒有的詞（例如「簽核」「氣象署」）。評測結果見 `tools/corpus-evaluator/results/`。發行版附上這三個檔案；自行建置時可先執行 `tools/bigram-trainer/fetch-models.sh` 下載同一組，或自行訓練。

組字接著游標前的漢字算，不當成句首：已送出「小模型」後打 ㄕˋ ㄕˋ 是「試試」，而不是句首常見的「逝世」。終端機讀不到游標前的文字，仍當成句首。

選過的字會依「前一個詞＋讀音」記下來，之後同樣的前文會優先選它（沿用 McBopomofo 的 UserOverrideModel，只存在記憶體，半衰期 1.5 小時，輸入法程式重新啟動後清空）。

## 自訂詞

輸入法選單的「編輯自訂詞…」用預設的文字編輯器開啟 `~/Library/Application Support/ProjectKey/phrases.txt`。每行一個詞和它的注音，音節以 `-` 分隔，例如 `小鍵 ㄒㄧㄠˇ-ㄐㄧㄢˋ`；`#` 開頭的行是註解。存檔後，下一次組字就會讀入。自訂詞優先於詞庫裡同讀音的詞，不打聲調時也查得到。

## 尚未實作

- 聯想詞：McBopomofo 的聯想詞資料需要另外產生。
- 滑鼠點選候選。
- 淺色候選視窗（深色以外只有 Liquid Glass）。
- 整句預覽列不顯示游標位置，未完成的注音一律畫在句尾。
- 候選清單的排序仍是詞庫分數，未依前後文調整。
- Universal binary：只編譯本機架構。程式碼簽章為 ad-hoc，尚未公證，無法散布給其他電腦。

`ProjectKey --preview <資料夾>` 會把候選視窗的幾個狀態畫成 PNG，供設計檢查。
