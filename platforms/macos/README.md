# macOS 輸入法

InputMethodKit 注音輸入法，大千鍵盤，候選視窗採用 [A 整句校對條](../../docs/design/candidate-window/notes.md) 第 02 輪的設計。選字引擎與詞庫目前使用 McBopomofo（MIT，固定 commit），組字與按鍵邏輯在 `../../core/engine`，與 Windows 共用，不依賴 InputMethodKit；`Sources/InputController.mm` 只負責把按鍵與畫面接到 IMK。

## 建置與安裝

發行版（Apple 晶片）：

```bash
brew install --cask koukeneko/tap/project-key
```

自行建置需要 Xcode（或 Command Line Tools）與 CMake，macOS 13 以上。

```bash
platforms/macos/build.sh     # 下載並編譯引擎、產生詞庫、跑測試、輸出 .build/ProjectKey.app
platforms/macos/install.sh   # 安裝到 ~/Library/Input Methods 並向系統註冊
```

安裝後到「系統設定 > 鍵盤 > 輸入方式」按「+」，在繁體中文下加入 Project Key。之後重新安裝不需要再加一次。

移除：刪掉 `~/Library/Input Methods/ProjectKey.app`，再從輸入方式清單移除。

## 按鍵

| 狀態 | 按鍵 | 動作 |
|---|---|---|
| 組字中 | 注音鍵、聲調鍵 3 4 6 7 | 輸入注音；聲調鍵結束音節。聲調可省略：拼成的音節不分聲調比對並直接顯示成字，接不上的注音開始下一個音節（ㄋㄧㄏㄠ 為「你好」）。單獨一個注音代表以它開頭的音節（ㄨㄇ 為「我們」） |
| | Space | 結束一聲音節；沒有還沒打聲調的注音時，開啟候選 |
| | ↓、Tab | 開啟候選。選字位置為游標前（預設，同系統注音）：游標前的詞。選字位置為游標後：游標在句尾時從第一個可疑處開始（用方向鍵移到句尾時則是最後一個字），否則從游標後的字開始（游標在詞中間時，可單獨換掉後半的字） |
| | Enter | 送出整句 |
| | ←、→、Home、End | 在字與字之間移動游標，新輸入的字插在游標處 |
| | Delete | 刪除一個注音符號或游標前的字 |
| | ⌦ | 刪除游標後的字 |
| | Esc | 清除未完成的注音；再按一次清除整句 |
| | ⇧ + 標點鍵 | 全形標點，例如 ⇧, 輸入「，」 |
| | 標點鍵 | `\` 或 `'` 輸入「、」，`[` `]` 輸入 `「` `」` |
| 選字中 | 1–6 | 選取所在那一列的字，選完跳到下一個可疑處（可在設定關閉，關閉時選完即結束選字） |
| | ←、→ | 移動選取 |
| | ↓ | 展開成多列候選，移到下一列的同一欄。每列 6 欄，長詞佔多欄。注音本身（如「ㄏㄡˋ」）接在第一列之後，選它會連同整句送出 |
| | Space、PageDown | 下一列；展開時往下捲 5 列 |
| | ↑ | 上一列；展開時在第一列收合，未展開時在第一列關閉候選、回到組字 |
| | PageUp | 上一列，停在第一列；展開時往上捲 5 列 |
| | Enter | 選定目前候選 |
| | Tab、⇧Tab | 跳到下一個／上一個可疑處 |
| | Esc | 展開時收合，否則回到組字 |
| | Delete | 回到組字 |
| 任何時候 | ⇪ | 在設定開啟「⇪ 切換中英」時（預設關），切換中／英，與單按 ⇧ 相同；大寫鎖定亮著時字母仍打小寫，大寫用 ⇧ |
| 任何時候 | 單按 ⇧ | 切換中／英，游標下方短暫顯示「ㄅ」或「A」 |
| 英文模式 | ⇥ | 剛才在英文模式打的大千鍵若是含聲調鍵的完整注音（如 ji3cl3），改成組字中的「我好」並切回中文；前面的英文不動。可轉換時游標下方會預覽轉換結果與 ⇥ 鍵帽；沒有預覽時 ⇥ 照常輸入。終端機（Terminal、iTerm2、Ghostty 等）收回不了已送給 shell 的字，不提供這項轉換 |
| 組字中 | ⇥ | 組字的按鍵若拼成英文單字（如 hello，且不是注音音節），改回英文並切到英文模式。可轉換時游標下方會預覽英文與 ⇥ 鍵帽；按過 Delete、方向鍵或選過字就不再判斷 |
| 組字中 | ⌃⇧P | 開關整句預覽 |

整句預覽分兩處設定：輸入時常駐在文字旁的預覽，以及選字時候選視窗下方的預覽，各有三種模式（永遠、有可疑字時、關閉），預設都是有可疑字時，在輸入法選單的「設定…」視窗中切換，設定會保存；⌃⇧P 開關目前這一處。「設定…」也可選擇候選視窗與中英提示的外觀：Liquid Glass（macOS 26 以上的預設），或深色，選字位置（游標後或游標前），以及開關選完跳到下一個可疑處、鄰鍵修正、記住選過的字（可清除紀錄）、⇪ 切換中英（預設關）、單按 ⇧ 切換中英，以及 ⇥ 的英文轉注音、注音轉英文（預設開）。最後一區「關於」列出版本、有無新版（查 GitHub 最新發行版）、授權與引擎及詞庫的來源。設定在下一次組字時生效。

鄰鍵修正：每個音節也比對按錯一個相鄰鍵的讀音，包括同一列左右（例如 ㄧㄡˇ 與 ㄧㄝˇ）與上下列（例如 ㄋ 與 ㄌ），依上下文決定是否改用；按錯成詞庫沒有的音節時也會改讀成相鄰的音節。只在有上下文模型時啟用。選單列圖示是系統繪製的「ㄅ」標籤，會跟著淺色與深色選單列變色。

## 可疑處的判斷

引擎走出的每個詞，若與同讀音的下一個候選分數差距小於 0.5（log10），就標為可疑。使用者選過的詞不再標示。這只能抓到同音詞的猶豫，抓不到斷詞錯誤，例如「重構成」被斷成「重／構成」。

## 上下文排序

有 `tools/bigram-trainer/.cache/bigram.bin` 時，`build.sh` 會把它放進 App，組字器依前兩個詞選字（bigram 與 trigram）；沒有時與 McBopomofo 的選字結果相同。同一個目錄有 `data.txt` 時，以它取代 McBopomofo 的詞庫：補上新酷音詞庫與訓練文字中 McBopomofo 沒有的詞（例如「簽核」「氣象署」）。評測結果見 `tools/corpus-evaluator/results/2026-11-05-bigram.md`。

選過的字會依「前一個詞＋讀音」記下來，之後同樣的前文會優先選它（沿用 McBopomofo 的 UserOverrideModel，只存在記憶體，半衰期 1.5 小時，輸入法程式重新啟動後清空）。

## 尚未實作

- 聯想詞：McBopomofo 的聯想詞資料需要另外產生。
- 滑鼠點選候選、出現與切換的動畫。
- 淺色候選視窗（深色以外只有 Liquid Glass）。
- 整句預覽列不顯示游標位置，未完成的注音一律畫在句尾。
- 個人化學習與自訂詞：每次組字都從詞庫預設值開始。
- 候選清單的排序仍是詞庫分數，未依前後文調整。
- Universal binary：只編譯本機架構。程式碼簽章為 ad-hoc，尚未公證，無法散布給其他電腦。

`ProjectKey --preview <資料夾>` 會把候選視窗的幾個狀態畫成 PNG，供設計檢查。
